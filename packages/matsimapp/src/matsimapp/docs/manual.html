マニュアル

      MatSimApp マニュアル

      スマホのブラウザから GPUMD の計算を投入・監視・結果確認するアプリです。計算は自宅 PC (WSL2) の GPU で動き、GPUMD_toolkit を経由して入力を作ります (v0.15.0)。アプリに戻る

      上の検索欄で、マニュアル全体を文字検索できます (Enter で次の一致、Shift+Enter で前、「/」キーで検索欄へ)。目次は、広い画面では左、スマホでは「目次」ボタンから開きます。

      第 1 部 はじめに

      1. このアプリでできること

      • 構造を用意する: ファイル (cif・POSCAR など)・Materials Project・テスト構造から取り込み、モデリング (置換・空孔・合金・表面・粒界・多結晶など) で加工します (9 章)。
      • 計算する: MD (温度・圧力を決めた分子動力学) と、静的計算・拡散・熱伝導・自由エネルギー・引張・フォノン・融点・構造相転移・メタダイナミクス (PLUMED) など 20 種類以上。どれを選べばよいかは 第 2 部。
      • 結果を見る: 実行中から進捗とグラフが更新されます。入力ファイル (run.in・plumed.dat) は説明つきで画面から見られます (14 章)。
      • 解析する: ボロノイ多面体・配位数と動径分布関数・配位多面体・短範囲秩序・原子分布・結晶構造の判定・アレニウスプロットなど。

      2. 起動と接続

      起動

      cd <MatSim のフォルダ>
./activate_app.sh        # Tailscale 経由で使う (./run.sh --tailscale と同じ)
      コマンド開ける場所
      ./run.shこの PC だけ (http://localhost:8020)
      ./run.sh --tailscaleTailscale 経由。Cookie が HTTPS 専用になります

      初めて入れるとき・パッケージを足したときは、uv pip install -r requirements.txt --python ~/.venv/gpumd312/bin/python を実行します (構造モデリングの atomsk_kit もここで入ります)。

      サーバーを止めても、実行中の GPUMD の計算は止まりません。次に起動したとき、実行中のジョブを見つけ直して続きを表示します。

      スマホからの接続

      スマホで Tailscale をオンにして、次の URL を開きます。

      https://<この PC の Tailscale の名前>:10000

      Tailscale の割り当ては設定済みです (Windows 側)。設定し直すときは PowerShell で次を実行します。マネオンズ (443 → 8000) とゆめぐりGO (8443 → 8010) とは別の番号です。

      tailscale serve --bg --https=10000 http://127.0.0.1:8020

      ブラウザの「ホーム画面に追加」で、アプリのように起動できます。

      最初のアカウント

      初めて開くとアカウント作成の画面になります。作れるのは最初の 1 つだけで、以後はそのアカウントでログインします (パスワードは 10 文字以上)。ログインしないと構造の閲覧も計算の投入もできません。

      3. 基本の使い方 (MD を流す)

      (1) 構造を用意する

      「構造」タブで追加します。

      • テスト構造を追加: 動作確認用の Cu (fcc) と MgO (岩塩型) をボタン 1 つで追加できます。
      • ファイルから追加: cif / POSCAR / CONTCAR / .vasp / .xyz (セル情報つき)。5MB まで。
      • Materials Project から追加: 組成式 (SiO2) か mp-id (mp-149) で検索して「取得」。慣用単位胞で取り込みます。先に「設定」タブで API キーを保存してください。
      • 計算結果から: 完了したジョブの画面で「最終構造を登録」を押すと、最終構造が一覧に入り、次の計算に使えます。

      (2) 条件を決める

      ホームの「MD」、または構造の画面の「この構造で MD」から始めます。構造の画面の「この構造で計算する」には計算メニューが並び、押すとその構造を選んだ状態で設定画面が開きます (構造を先に選んでから計算を決められます)。

      設定画面の「構造」は、選んでいる構造 (名前・組成・原子数・取得元) だけが出ています。「変える」で一覧を開き、名前・組成・元素で探す (空白で区切ると、すべてを含むもの。「Mg O」なら Mg と O を含む構造)、取得元 (アップロード・Materials Project・モデリング・計算結果・テスト構造) で絞る、新しい順・名前順・原子の少ない順に並べ替える、ができます。

      項目内容
      スーパーセルa × b × c の繰り返し数。既定では、セルの厚みが各方向 12 Å 以上になる数が入ります。原子数が 10,000 を超えると警告が出ますが、そのまま実行できます (3D 表示は間引きます)。
      ポテンシャル既定は汎用の NEP89。構造の元素に対応しているかがその場で表示されます。
      温度・圧力の流れステージを上から順に実行します。「定温 (NVT)」「定温定圧 (NPT)」「昇温」「アニール」を押すとひな形が入り、数値を直して使えます。
      終了温度入れると、そのステージの間に温度が直線的に変わります (昇温・降温)。空欄なら一定。
      詳細設定ジョブ名、時間刻み (fs)、熱力学量の出力間隔、トラジェクトリの保存間隔 (0 で保存しない)、MD 前の構造最適化。

      任意の温度プロファイルは、ステージを並べて作ります (例: 300 K 一定 → 300→1000 K → 1000 K 一定 → 1000→300 K)。ステージは 20 個まで、合計 1,000 万ステップまでです。

      (3) 確認して実行する

      「内容を確認する」を押すと、原子数・ステップ数・所要時間の目安と、生成される入力ファイル (run.in、PLUMED を使う計算では plumed.dat も) が出ます。入力ファイルは行ごとの説明つきで見られます (14 章)。問題なければ「この内容で実行する」。所要時間の目安は、同じポテンシャルで完了したジョブの実測の速度から計算します (実測がない最初の 1 回は粗い目安です)。

      迷ったときの考え方

      • 最初は小さく・短く: 数百原子・数万ステップで流し、「計算が回るか」「おかしな値が出ないか」を見てから大きくします。
      • ポテンシャルを先に確かめる: 静的計算で格子定数・弾性定数を、文献や DFT の値と比べます。ずれていれば、その先の計算も信用できません (5 章)。
      • 全体像 → 精密: 相転移なら「昇温 MD で何が起こるか見る」→「構造相転移のスキャンでおおよその温度・圧力」→「自由エネルギーで正確な値」の順。
      • 結果が変わらないか確かめる: 系を大きくする・計算を長くする・時間刻みを小さくするで、値が変わらなければ信用できます。

      5. 計算の前に決めること

      ポテンシャル

      • 既定の NEP89 は 89 元素に使える汎用のポテンシャルです。動作確認やおおまかな傾向を見るのに向いていますが、定量的な値は材料によって大きくずれます。
      • 例: NEP89 では、Ti の安定な構造の順番 (hcp が最も安定) が第一原理計算と逆になり、hcp の Fe には物理的でない高密度のエネルギーの谷があります (11 章)。
      • 確かめ方: (1) 静的計算で格子定数・弾性定数・状態方程式を文献値と比べる。(2) 相転移を扱うなら、関係する相 (bcc・fcc・hcp など) を同じ体積で静的計算し、エネルギーの順番が正しいか見る。(3) 融点を求めて実験と比べる。
      • その材料用のポテンシャル (nep.txt) があれば、「設定」タブで追加して選びます。

      • 静的計算: 構造最適化は FIRE (セルも最適化できる)、弾性定数は原子を動かさない ±ひずみの応力の差、状態方程式は 21 点。

      • 出力は GPUMD と同じ形式 (thermo.out・dump.xyz・restart.xyz・omega2.out・D.out) で書くので、結果のグラフ・最終構造の登録・解析 (ボロノイ・配位数など) はそのまま使えます。計算の指示は ase_job.json、run.in は結果の表示のための記録 (GPUMD では実行していません)。
      • 仕組み: SevenNet・PyTorch (CUDA 13 版)・phonopy は、アプリと同じ環境 (~/.venv/gpumd312) に入っています。計算はジョブごとに別のプロセスで動かします。別の環境を使うときは MATSIM_ML_PYTHON で指定します。テンソル積の高速化 (cuEquivariance) を使い、使えないときは使わずに計算します (7〜11 倍遅くなる)。ホームの「計算環境」に SevenNet の行が出ます。

      ポテンシャルを対象の材料に合わせる (ファインチューニング)

      NEP89 は速い (GPUMD で数百万原子も動く) 代わりに、材料によっては精度が足りません。SevenNet は精度が高い代わりに数十倍遅い。そこで、SevenNet を先生にして NEP89 を対象の材料向けに学び直し、GPUMD の速さのまま SevenNet に近い精度のポテンシャルを作ります (知識の蒸留)。計算の種類「ファインチューニング (SevenNet → NEP)」で行います。

      GPUMD のファインチューニングに要るのは、(1) 出発点のモデル (NEP89 の nep89_20250409.txt と .restart。GPUMD に付いてくる) と、(2) 正解のエネルギー・力・ビリアルの付いた学習データ (train.xyz) の 2 つです。ふつうは (2) を DFT で作りますが、ここでは SevenNet で作ります。

      1. 0 段目 (最初にまとめて学ぶ): 元のポテンシャル (NEP89) で、指定した温度ごとに MD をして構造を多めに集めます。似た構造を除いて (下の D 最適な選び方) 最大「0 段目に学ぶ構造の上限」(既定 50) まで選び、SevenNet で計算して 1 回学びます。大きめの構造 (数百原子) では 1 構造に多くの原子環境が入るので、似たものを除くと数構造しか残らないことがあります (256 原子の Cu で 40 構造中 6〜9 構造)。もっと学ばせたいときは「0 段目に学ぶ構造の下限」を指定すると、届かない分を外挿度の高い (学習データからより外れている) 構造から順に足します (既定 0: 似たものを除いた分だけ)。NEP89 と SevenNet のエネルギーの基準のずれ (Cu で約 190 meV/atom) もここでそろいます。
      2. 1 段目から (学ぶ必要があるかを判断): いまの NEP で MD をして構造を集め、次の 2 つで判断します。
        • 外挿度 γ (TorchNEP の MaxVol): 学習データの原子環境が張る範囲 (active set) から、新しい構造の原子がどれだけ外れているか。1 以下なら範囲の中で、しきい値 (既定 2) を超えた構造は「学習データにない環境」として学びます。先生を使わずに判断できます。
        • 先生 (SevenNet) との力の誤差: 範囲の中でもまだ合っていない構造を拾います。95% の構造がしきい値 (既定 0.05 eV/Å) を下回るまで学びます。
      3. 足して学び直す: 外挿している構造は、γ の高い順に、すでに選んだものと似ていない構造だけを選びます (1 つ選ぶたびに範囲を広げて測り直すので、ダブりが自然に除かれる)。残りの枠で、誤差の大きい構造を MD の時間の並びで偏らないように足します。
      4. 終わり: γ がしきい値を超える構造がなく、誤差もしきい値以下になったら終えます。
      • γ と誤差は、どちらもその段の MD で新しく集めた (まだ学習していない) 構造で測ります。
      • 最初の学習データには、元の構造の伸び縮み (状態方程式の 7 点) と、ランダムな変位・ひずみの構造も入れます。
      • 0 段目は NEP89 から fine_tune (89 元素から、構造の元素だけを取り出して学び直す)。1 段目からは前の段のポテンシャルの続きから学びます (nep.restart と import_q_scaler 1)。GPUMD の fine_tune の出発点は 89 元素の NEP89 だけなので、ファインチューニング済みのポテンシャルからさらに学び直すときも「続きから」です (同じ元素の組の構造だけ)。その場合は「0 段目に学ぶ構造の上限」を 0 にして 0 段目を飛ばせます。
      • GPUMD にも MD 中に γ を見張る compute_extrapolation がありますが、この PC (WSL2) では使えません。CPU と GPU から同じ managed メモリを同時に触る作りで、WSL2 の GPU はそれができない (concurrentManagedAccess = 0) ため、計算を始めた直後に落ちます。代わりに、MD で集めた構造の γ を TorchNEP で計算しています。
      • できた nep.txt は「ジョブ名 (FT #番号, 先生)」という名前でポテンシャルの一覧に登録され、MD やほかの計算でそのまま選べます。restart も一緒に保存するので、別の条件 (温度など) でさらに学び直す出発点にもなります。一覧から消すと restart も消えます。
      • 結果の画面: 段ごとの力の誤差 (平均・95%・学習データでの誤差)、段ごとの外挿度 γ、段ごとの記録 (集めた・外挿していた・誤差が大きかった・足した構造の数)、状態方程式 (先生・元・学び直した後。エネルギーは最小を 0 に)、力の比較 (点が y = x の線に近いほど先生に合う)。
      • 入力の目安: 先生は精度の高い SevenNet-MF-ompa (MP と同じ PBE) が既定。MD の温度は、あとで使いたい温度の範囲を覆うように (例: 300,700,1100 K)。構造は 1000 原子まで、セルの厚みは 12 Å 以上 (NEP89 のカットオフ 6 Å の 2 倍)。
      • 時間の目安 (RTX 5070 Ti): 256 原子の Cu、2 温度 × 4000 ステップ、世代数 1000 で、1 段が約 1 分 (全体で 3〜4 分)。学習の時間は 学習データの原子数 × 世代数 に比例します。
      • 例 (256 原子の Cu、先生 7net-0): 0 段目で 40 構造から似ていない 8 構造を選んで学び、1 段目で γ が 2 を超えた構造 (最大 2.7) と誤差の大きい構造を足し、2 段目で γ 最大 1.9・力の誤差 (95%) 0.036 eV/Å (元の NEP89 は 0.10 eV/Å) になって終わりました。状態方程式は先生とほぼ重なります。
      • 注意: できるのは「先生 (SevenNet) に近いポテンシャル」です。先生の誤差 (DFT との差) はそのまま残ります。MD で行かなかった構造 (別の相・表面・欠陥など) では精度は保証されないので、使う状況の構造 (例: 表面の計算なら表面のスラブ) で学び直してください。
      • 学習は GPU に合わせて計算をその場でコンパイルします。PATH の /usr/bin/nvcc (CUDA 12.0) は RTX 50 系に対応していないので、CUDA 13 (/usr/local/cuda/bin、MATSIM_CUDA_BIN) を使います (使えないと約 2 倍遅い)。

      系の大きさ (スーパーセル)

      • セルの厚みは、各方向でポテンシャルのカットオフの 2 倍以上が必要です (既定で 12 Å 以上になるように繰り返します)。
      • 目安: 物性値 (弾性・熱膨張) は数百〜数千原子、拡散は数千原子、相転移・融点・欠陥は数千〜数万原子。小さい系では、相転移が起こりにくい・起こる温度がずれる・統計誤差が大きい、などの問題が出ます。
      • 計算時間は原子数とステップ数にほぼ比例します。確認画面の「所要時間の目安」を見て決めます。

      時間刻みと計算の長さ

      • 時間刻み: 金属・酸化物は 1〜2 fs、水素を含む系は 0.5 fs 程度。大きすぎるとエネルギーが保存されず、計算が壊れます。
      • 長さの換算: 時間刻み 1 fs で 1,000 ステップ = 1 ps、100 万ステップ = 1 ns。
      • 平衡化: 温度・体積が落ち着くまで (10〜50 ps)。結果のグラフで、温度や体積が一定の値のまわりを揺れているか確かめます。
      • 本計算の目安: 熱膨張・弾性 数十 ps、拡散 数百 ps〜数 ns、熱伝導率 数 ns、相転移・メタダイナミクス 数百 ps〜数 ns。

      • 系を大きく・計算を長くして、値が変わらないか見る (系の大きさ・時間の依存性)。

      フォノンの振動のようす

      完了したフォノン分散のジョブの画面に「振動のようす」が出ます。分枝 (バンド) を 1 つ選び、q をスライダーで動かす (高対称点のボタンで Γ・X などへ飛ぶ、分散曲線をタップしても選べる) と、その振動で原子がどう動くかを、3D 表示の青い矢印 (変位の向き) と原子の動きで示します。

      • 振動数と q (逆格子の分数座標) を表示し、選んだ分枝と q を分散曲線に印で示します。虚振動 (負の振動数) なら、その向きに構造が不安定です。
      • 音響モード (分枝 1〜3): q が小さいと、となりの原子どうしが同じ向きに動く長い波 (音波)。Γ 点では結晶全体の平行移動です。光学モード: セルの中の原子どうしが逆向きに動きます (Γ 点ではどのセルも同じ動き)。
      • 表示は、基本単位胞を整数倍した、なるべく直方体に近いセル (fcc・bcc なら立方体の慣用単位胞) を並べたものです。原子の動きと矢印は独立に設定できます: 「原子を動かす」のオン・オフと「動きの大きさ」(いちばん大きく動く原子の振れ幅。止めると平衡の位置に戻る)、「矢印を描く」のオン・オフと「矢印の長さ」(いちばん大きく動く原子の矢印の長さ)。並べるセルの数も変えられます。動きの大きさと速さは見やすさのためで、本当の振幅や周期ではありません。
      • 仕組み: GPUMD が書く q 点ごとの動的行列 (D.out) をサーバーで対角化して固有ベクトルを求め、セル R の原子 a の変位を Re[ea/√ma · exp(i(q·(R + ra) − ωt))] で描きます。振動数は分散曲線 (GPUMD の omega2.out) と一致することを確かめてあります。

      衝突・成膜・表面は、真空層のある表面スラブが必要です (構造のモデリングの「真空層を加える (表面)」)。入れていないチュートリアル: NEP の学習・ファインチューニング (11〜13, 26)、DP (14)、FCP (18)、波束 (17)、摩擦 (31, ILP が必要)、格子動力学の熱伝導率 (25, hiPhive・phono3py が必要)、振動の可視化 (05)、多成分の熱輸送 HNEMDEC (29)、赤外スペクトル (15, 双極子の NEP が必要)、超イオン伝導体の熱輸送 (28)。重なるため入れていないもの: 01・03・09・10・24 (既存の静的計算・熱輸送・拡散)、22 (モデリングと MD で可能)。

      8. 温度スキャンとアレニウスプロット

      「拡散・イオン伝導」の「温度スキャン」に 600, 700, 800, 900, 1000 のように温度を並べると、温度ごとにジョブを作ってまとめて投入します (2〜20 点)。投入すると「アレニウス解析」の画面に移り、終わったジョブから順に解析に加わります。別々に流した拡散のジョブも、「ジョブ」タブの「アレニウス解析」や各ジョブの「アレニウスプロット」から選んで解析できます。

      • 横軸 1000/T に対して、元素ごとの ln D と、イオン伝導度の ln(σT) を直線で当てはめ、傾きから活性化エネルギー Ea [eV] (と誤差)、前指数因子、R²、300 K への外挿値を出します。伝導度は ln σ での当てはめにも切り替えられます。
      • 温度は既定で本計算の実測の平均温度を使います (「解析の条件」で設定値に切り替えられます)。

      グラニュラー構造 (円柱粒)

      元の構造 (単位胞) から円柱の結晶粒を作って箱に並べ、粒のすき間を埋めた柱状組織を作ります。

      • 粒の並べ方: ランダム (数・平均半径・半径のばらつき・粒どうしの最小のすき間を指定) か、六方の規則配列。ランダムは面積率 80% 程度まで詰められます。
      • 粒の方位: z 軸まわりにランダム (柱状。z 方向は周期的になるよう、厚さを結晶の周期の整数倍に丸めます) か、3 次元でランダム。
      • すき間: 原子をランダムに詰める (結晶の数密度に対する充填率と原子どうしの最小距離を指定。アモルファス状の粒界相になります)、別の結晶で埋める、空けておく、から選びます。
      • 粒は、元の結晶を大きく並べて回し、Atomsk の -select cylinder で円柱に切り出しています。

      モデリングで作った粒界・すき間・欠陥のまわりは緩和していません。計算に使う前に MD (アニールや構造緩和) をかけてください。構造の一覧とジョブの一覧では、「選択」を押すと複数を選んでまとめて削除できます (実行中・実行待ちのジョブは選べません。先に中止してください)。

      10. 自由エネルギー面 (PLUMED) の使い方

      計算メニューの「自由エネルギー面 (PLUMED)」(発展) から開きます。PLUMED のメタダイナミクス (well-tempered) で、集団変数 (CV) に沿った自由エネルギー面を作ります。融解・結晶化・相転移の障壁や、どちらの状態が安定かを調べます。PLUMED を使ったことがなくても使えるよう、入力ファイル (plumed.dat) はアプリが書き出します。

      メタダイナミクスとは

      ふつうの MD では、原子は谷 (安定な状態) の中で揺れているだけで、障壁の高い変化 (相転移・結晶化など) は計算できる時間の中ではめったに起こりません。メタダイナミクスでは、今いる場所に小さな山 (ガウス関数) を少しずつ積んでいきます。谷が山で埋まると、系は押し出されて障壁を越え、別の谷 (別の構造) へ移ります。最後に、積んだ山の形を裏返すと、谷の深さと障壁の高さ、つまり自由エネルギー面が得られます。

      「well-tempered」は、山の高さを少しずつ小さくしていく方法です。値が収束しやすく、高すぎる (関係のない) 所まで埋めずにすみます。

      CV (集団変数) とは

      数百〜数万個の原子の座標を、1〜2 個の数にまとめたものです。例: 「全原子の配位数の平均」「bcc との類似度 (0〜1)」「セルの c/a」。山は CV の値の場所に積むので、CV が、どの方向に押すかと、どんな自由エネルギー面が得られるかを決めます。アプリの CV の選択は plumed.dat の書き方の切り替えですが、それ以上に、計算の結果そのものを左右します。

      よい CV の条件

      1. 始めの状態と目的の状態で、値がはっきり違う (例: bcc の Fe と hcp の Fe で、bcc との類似度が 0.91 と 0.11)。
      2. 転移の途中の道筋に沿って、値がなめらかに変わる。
      3. 転移に関係する遅い動きを、ほかに取り残していない (取り残すと、CV を押しても転移が起こらない)。

      悪い例: fcc ↔ hcp の転移に「配位数」を選ぶと、どちらも 12 なので区別できず、いくら押しても転移しません。

      • 配位数の平均: 各原子のとなりの原子の数を数えて平均します。中心の元素ととなりの元素を選べます (空欄ならすべて)。となりと数える距離は、空欄なら最近接距離の 1.2 倍 (fcc なら第 1 近接だけ、bcc なら第 2 近接まで) で、この距離の 0.4 Å 手前までを 1、この距離で 0 としてなめらかにつなぎます。
      • Q6 の平均: まわりの原子の並びの規則正しさ (Steinhardt の結合配向秩序)。計算が重く、PLUMED の分だけ数倍遅くなります。
      • Q4 の平均: fcc (約 0.19)・hcp (約 0.10)・bcc で値が違うので、構造相転移にも使えます。Q6 と同じく重い。

      • セルの比 c/a・b/a: セルの辺の長さの比 (最初を 1)。NPT のときだけ選べます。
      • 体積 (1 原子あたり): NPT のときだけ選べます。
      • 2 原子の距離: 指定した 2 つの原子のあいだの距離 (Å)。

      手順 (初めての人向け)

      1. CV の候補を記録する: 「やり方」を「CV を記録するだけ (バイアスなし)」にし、始めの構造と目的の構造で、候補の CV を流します (目的の構造は、モデリングで作るか、別の計算の最終構造を登録)。結果の「CV の時間変化」で、2 つの状態の値がはっきり離れているか、ゆらぎ (値の振れ幅) がどれくらいかを見ます。
      2. パラメータを決める: 下の目安で、ガウス関数の幅・高さ・バイアス係数を決めます。
      3. メタダイナミクスを流す: 「やり方」を「メタダイナミクス」に戻して流します。まず短く流して、CV が動き始めるかを確かめてから長くします。
      4. 収束を確かめる: 結果の「自由エネルギー曲線」で、途中 (25%・50%・75%) までの曲線と最後の曲線の形がそろっているかを見ます。

      結果の読み方

      • 自由エネルギーは系全体の値です (1 原子あたりではありません)。1 原子あたりにするなら原子数で割ります。
      • 「CV を記録するだけ」では、MD 中に訪れた範囲の分布から F = −kT ln P を出します (最初の 20% を除く)。障壁を越えない変化は見えません。

      11. 構造相転移 (温度・圧力スキャン)

      計算メニューの「構造相転移 (温度・圧力スキャン)」(物性) から開きます。温度か圧力を段階的に変えながら、セルの形も自由に変えられる NPT (三斜晶、確率的セル再スケーリング) を流し、結晶構造の比率・体積・格子の変化から転移を探します (例: Ti の hcp → bcc の昇温、Fe の bcc → hcp の加圧)。

      • 変えるもの (温度 / 圧力)、始めと折り返しの値、点の数、各点のステップ数を決めます。「帰りも流す」で、折り返したあと同じ点を逆にたどります。
      • 各点の後半の構造を数枚 (最大 5 枚) 「結晶構造の判定」(17 章) にかけて平均し、fcc・hcp・bcc・正二十面体・その他の比率を出します。各点の構造は、結晶 (fcc・hcp・bcc・正二十面体) のうち最も多いものとします (高温の bcc などは熱ゆらぎで半分以上が「その他」に判定されることがあるため。結晶らしい原子が 2 割未満なら「その他」= 液体など)。その構造が入れ替わった所を「行き / 帰りの転移」として、その前後の値と、体積の変化を出します。行きと帰りの両方で転移すれば、その差 (ヒステリシスの幅) と真ん中 (転移点の目安) も出します。
      • グラフ: 体積・ポテンシャルエネルギー・セルの辺の長さ (始めを 1)・セルの角度 (行きと帰りを重ねる)、結晶構造の比率 (行き・帰り)。各点の値は analysis/transition_table.csv にもあります。
      • MD の転移は、過熱・過冷却 (圧力では過圧) で本当の転移点よりずれます。小さい系・短い時間ほど大きくずれるので、行きと帰りの真ん中を目安にし、正確な転移点は自由エネルギー (10 章・自由エネルギーの計算) などで確かめます。

      ポテンシャルの精度に強く左右されます。汎用の NEP89 で試したところ、Fe は加圧で bcc → hcp に転移しましたが (8〜12 GPa、実験は約 13 GPa)、そのあと体積が実際より 3 割ほど縮みました (NEP89 の hcp Fe に、7.5 Å³/原子 あたりの物理的でないエネルギーの谷があるため)。Ti は 1200〜1300 K で hcp → bcc に変わりましたが (実験は約 1155 K)、冷やしても hcp に戻りませんでした (NEP89 では 0 K で bcc・fcc が hcp より安定で、第一原理計算と順番が逆のため)。転移点を議論するには、その材料の相を学習データに含めたポテンシャルを使ってください。

      15. 解析: ボロノイ多面体

      完了したジョブの「ボロノイ解析」(または構造の画面の「ボロノイ解析」) から開きます。各原子のボロノイ多面体を、3〜6 角形の面の数 ⟨n3,n4,n5,n6⟩ で分類します (7 角形以上の面があれば後ろに続けて書きます)。例: ⟨0,0,12,0⟩ 正二十面体 (金属ガラス・液体)、⟨0,6,0,8⟩ bcc、⟨0,12,0,0⟩ fcc・hcp、⟨0,6,0,0⟩ 単純立方・岩塩型。

      • 指数の読み方: 原子のまわりを、となりの原子との垂直二等分面で囲んだ多面体の面を形ごとに数えたものです。⟨n3,n4,n5,n6⟩ = 三角形・四角形・五角形・六角形の面の枚数で、合計が配位数 (となりの原子の数) です。例: ⟨1,5,5,1⟩ = 配位数 12、三角形 1・四角形 5・五角形 5・六角形 1。画面の「ボロノイ指数の読み方」を開くと同じ説明が出ます。一覧と表には、指数ごとにこの「面の内訳」を書いています。
      • まとまり: 指数は数百種類に分かれることが多いので、似たもの同士を 7 つにまとめます。正二十面体 ⟨0,0,12,0⟩ / 二十面体に近い (五角形が 8 枚以上で 6 割以上) / Frank–Kasper型 ⟨0,0,12,n6≥1⟩ / fcc・hcp ⟨0,12,0,0⟩ / bcc ⟨0,6,0,8⟩ / 結晶に近い (四角形が五角形より多い) / 乱れた多面体 (それ以外)。結果の「まとまりで見る / 指数で見る」で、比率のグラフ・色塗り・時間変化の分け方を切り替えます (既定はまとまり。まとまりの色は固定)。
      • ボロノイ指数の比率 (上位の種類とその他) と、配位数の分布をグラフにします (距離で数える配位数は 18 章)。すべての種類の表もあります。
      • 「色を付ける種類」で種類を好きなだけ選ぶと、その原子を 3D 表示で色塗りします (色はグラフと同じ)。「選んでいない原子を隠す」で、選んだ原子だけを表示できます。
      • ジョブではトラジェクトリから等間隔にフレームを選び (既定 20 枚)、比率の時間変化を描きます。最終構造で多い種類に加えて、最初のフレームで多かった種類も追います (融ける前の結晶の減り方などが見えます)。トラジェクトリを保存していないジョブは最終構造だけです。
      • 「数える多面体」で元素を選ぶと、その元素を中心とする多面体だけを数えます (CuZr の Cu 中心など)。
      • 熱ゆらぎでできるごく小さな面 (全表面積の 1% 未満) とごく短い辺 (平均原子間隔の 0.18 倍未満) は数えません (詳細設定で変えられます)。この既定で、300 K 程度に揺れた fcc の約 9 割・bcc のすべてが正しい指数になります。高温の液体は指数が非常に多くの種類に分かれるので、急冷や構造最適化をした構造で解析するのが一般的です。
      • 解析は「解析のジョブ」として動きます。「解析を始める」を押すと、進み具合 (解析したフレーム数と残り時間の目安) が出ます。画面を閉じても解析は続き、「ジョブ」タブの一覧からも開けます。中止・削除・まとめて削除も計算のジョブと同じです。
      • 解析のジョブは GPU を使わず、GPU の計算とは別の列で 1 件ずつ動きます (GPU の計算の順番待ちには割り込みません)。サーバーを止めて途中で終わった解析は、次の起動時に最初からやり直します。
      • 同じ条件で済んでいる (または実行中の) 解析があれば、新しく作らずにそれを開きます。結果は解析のジョブの result.json にあります。

      16. 解析: 原子分布

      完了したジョブの「原子分布」(または構造の画面の「原子分布」) から開きます。選んだ元素の原子を 1 つの軸に射影し、横軸を座標、縦軸を分割幅ごとの原子数にして描きます (膜の厚み方向の分布、界面への偏析、拡散のプロファイルなど)。

      • 元素はボタンで複数選べます (選ばなければすべて)。元素ごとの線と合計 (点線) を描きます。
      • 射影する軸 (x / y / z) と分割幅 (Å) を選べます。直方体のセルなら 0〜セルの長さ、斜めのセルなら原子の座標の範囲を区切ります。区間の境目にちょうど乗った原子は上の区間に入ります。
      • ジョブでは、トラジェクトリの最後の何枚かで平均できます (平均するフレーム数。0 で最終構造だけ)。
      • 「CSV で保存」で、区間の中心の座標と元素ごとの原子数を保存できます。

      17. 解析: 結晶構造の判定

      完了したジョブの「結晶構造の判定」(または構造の画面の「結晶構造の判定」) から開きます。原子ごとに、まわりの原子の並び方が fcc・hcp・bcc・正二十面体のどれと同じかを判定します (adaptive CNA: 近い順に 12 個か 14 個のとなりを取り、となりどうしのつながり方を理想的な結晶と比べる)。となりまでの距離を原子ごとに決めるので、格子定数や元素によらず、温度で揺れた結晶も判定できます。

      • 比率の棒グラフ、選んだ構造の原子の色塗り (3D)、トラジェクトリの時間変化 (既定 40 フレーム)、元素ごとの比率 (2 元素以上)。
      • どれにも当てはまらない原子は「その他」です (液体・粒界・表面・転位の芯など)。fcc の中の積層欠陥・双晶境界は hcp になります。ダイヤモンド構造は今は判定できず「その他」になります。高温の結晶 (特に bcc) は、熱ゆらぎで「その他」と判定される原子が増えます。
      • ボロノイ解析と同じく「解析のジョブ」として動き、進み具合が出ます。CNA はボロノイ解析より 10 倍ほど速いので、原子数 × フレーム数 が 400 万まで解析します。

      18. 解析: 配位数

      完了したジョブの「配位数」(または構造の画面の「配位数」) から開きます。各原子のまわりで、ある距離 (カットオフ) の内側にある原子の数を数えます。

      • 数える距離: 空欄なら、元素の組み合わせごとの動径分布関数 g(r) の「第 1 の谷」(最初の山のあとの最も低い所) にします。結晶では第 1 近接と第 2 近接のあいだ、液体では第 1 配位殻の外側です。値を入れると、その距離ですべての組み合わせを数えます。
      • 動径分布関数 g(r): 全体と、元素の組み合わせごと (部分動径分布関数) を描き、数えた距離を点線の縦線で示します。どこまでを「となり」と数えたかを確かめられます。
      • 中心の元素と数えるとなりの元素: 2 元素以上のとき選べます (既定は「1 つ目の元素のまわりの 2 つ目の元素」)。「すべて」は、中心ならすべての原子、となりならすべての元素です。イオン結晶では陽イオンのまわりの陰イオン (例: MgO の Mg のまわりの O = 6) を見るのが一般的です (となりを「すべて」にすると、Mg のまわりの Mg 12 個も足して 18 になります)。
      • 図: 配位数の分布 (棒グラフ)、元素の組み合わせごとの平均の表、配位数での 3D の色塗り (少ないほど青、多いほど赤。選んだ配位数の原子だけ表示もできる)、トラジェクトリの平均の配位数の時間変化。
      • 時間変化の数える距離: 既定では、フレームごとにその時点の g(r) の谷から決め直し、その変化もグラフにします。途中で構造が変わる計算 (例: hcp → bcc の Ti で 12 → 14、冷えた bcc で約 8) でも、その時点の構造に合った距離で数えます。外すと最終構造で決めた距離をすべてのフレームに使います (同じ距離で比べたいとき)。距離を指定したときは、すべてのフレームでその距離です。
      • ボロノイの配位数との違い: ボロノイ解析 (15 章) の配位数は多面体の面の数です。fcc・hcp はどちらも 12 ですが、bcc はボロノイでは 14、距離では完全な結晶で 8、熱で第 1・第 2 近接の山がつながると 14 になります。液体はどちらも 12〜14 くらいに広がります。
      • 目安: fcc・hcp 12、bcc 8 (または 14)、ダイヤモンド 4、岩塩型 6 (陽イオンのまわりの陰イオン)、液体の金属 12 前後。
      • ボロノイ解析と同じく「解析のジョブ」として動きます。原子数 × フレーム数 が 400 万まで解析します (3 万原子 1 枚で 5 秒ほど)。

      19. 解析: 短範囲秩序 (ウォーレン・カウリー)

      完了したジョブの「短範囲秩序」(または構造の画面の「短範囲秩序」) から開きます。合金・化合物で、ある元素のまわりに別の元素がランダムより多いか少ないかを、近接の殻ごとに調べます (元素が 2 種類以上の構造)。

      • 定義: 殻 k (第 k 近接) で、元素 i のまわりにいる原子のうち元素 j の割合を pij、元素 j の全体の割合を cj として、αij = 1 − pij / cj。
      • 読み方: 違う元素の組 (例: Cu–Ni) で読みます。負 = 違う元素どうしが好まれる (規則化)、0 = ランダム、正 = 同じ元素どうしが集まる (クラスター化・相分離)。同じ元素の組 (表の対角) は符号の意味が逆です。2 元系では ciαij = cjαji。
      • 目安: B2 (CsCl 型) の第 1 殻で −1・第 2 殻で +1、L1₂ (Cu₃Au) の Au のまわりの Cu で −1/3、ランダム合金で 0、2 相に分かれた合金で正。規則合金では殻ごとに符号が入れ替わり、相分離では遠くの殻まで正が続きます。
      • 殻: 全体の動径分布関数 g(r) の谷を境目に、第 3 殻まで分けます (g(r) のグラフに境目を表示)。熱で山がつながると殻は合わさります (bcc の第 1・第 2 近接など)。
      • ゆらぎ (±σ): 原子数が有限なので、ランダムな並びでも α は 0 からずれます。その目安 σ を表に添え、|α| が 2σ より小さいマスは薄く表示します (ランダムと区別できない)。原子数を増やすと σ は小さくなります。
      • 図: 殻ごとの色付きの表 (青 = 負、赤 = 正)、違う元素の組の棒グラフ、殻ごとの変化、g(r) と殻の境目、原子ごとの局所的な秩序度の 3D の色塗り (第 1 殻で、同じ元素に囲まれた原子は赤、違う元素に囲まれた原子は青)、第 1 殻の α の時間変化 (殻の境目はフレームごとに決め直し)。
      • MD では原子はほとんど入れ替わらないので、秩序化の過程を見るには Monte Carlo (原子の入れ替え) と組み合わせます。

      20. 解析: 配位多面体

      完了したジョブの「配位多面体」(または構造の画面の「配位多面体」) から開きます。中心の原子 (Si・Ti など) のまわりの配位原子 (O など) がつくる多面体を見つけ、形・つながり方・ゆがみを調べます。酸化物・ガラス・イオン伝導体の構造の解析に使えます。

      • 中心と配位の元素: 自動では、O・F・S・N・Cl などの陰イオンがあれば、それを配位する元素に、ほかの元素を中心にします (なければすべての元素)。解析のあとは、構造の元素から選び直せます (例: SrTiO₃ で中心を Ti にすると TiO₆ 八面体、Sr にすると SrO₁₂)。
      • 配位と数える距離: 空欄なら、中心と配位の組み合わせの g(r) の第 1 の谷 (18 章と同じ)。
      • 形の判定: 中心から見た配位原子どうしの角度をすべて求めて小さい順に並べ、理想形 (直線・平面三角形・三角錐・四面体・平面四角形・シーソー・三方両錐・四角錐・八面体・三角柱・五方両錐・一冠八面体・立方体・正方逆柱・三冠三角柱・立方八面体・反立方八面体・正二十面体) の並びと比べて、最も近い形にします。角度の並びは多面体の向きや原子の番号によらないので、回転させて重ねる必要がありません。平均のずれが 15° を超えるものは「n 配位 (不規則)」。熱ゆらぎだけでも数度はずれます。
      • ゆがみ: 理想形からのずれ (角度、度) と、結合の長さのゆがみ (平均からの差の平均 ÷ 平均)。
      • つながり方: 2 つの多面体が共有する配位原子の数で、頂点共有 (1)・辺共有 (2)・面共有 (3 以上)。多面体ごとに、配位原子を共有している別の多面体の数を Qⁿ の n とします (SiO₄ のケイ酸塩なら架橋酸素の数に当たり、Q4 = 3 次元の網目、Q0 = 孤立した四面体)。例: ペロブスカイトの TiO₆ は頂点共有で 6 個、岩塩型の MgO₆ は辺共有 12 + 頂点共有 6、クリストバライトの SiO₄ は頂点共有で Q4。配位する元素が「すべて」か中心と同じ元素 (金属) のときは出しません。
      • 図: 形ごとの割合の棒グラフと表、3D 表示に多面体を形ごとの色で半透明に描く (描く形を選べる。1500 個まで)、配位数の分布、共有のしかた、Qⁿ、ずれの分布、形の割合の時間変化。

      25. MatSimAPI と MatSimApp

      計算を動かす部分 MatSimAPI (matsimapi) と、画面の部分 MatSimApp (matsimapp) に分かれています。画面でできる計算はすべて MatSimAPI を呼んでいます。

      パッケージ担当場所
      matsimapi構造・ポテンシャル・計算・ジョブのキュー・解析、Python API、コマンド、MCP サーバーpackages/matsimapi
      matsimapp画面、ログイン、マニュアルpackages/matsimapp
      atomsk-kit構造モデリングに使う Atomsk のキットpackages/atomsk_kit

      画面・Python・MCP は同じデータ置き場を使うので、Python で投入したジョブを画面で見られます (ログインのアカウントは画面だけのものです)。GPU は 1 枚なので、ジョブを動かす係 (ワーカー) は常に 1 つで、画面とは別のプロセス matsimapi worker が務めます。画面のサーバーを止めても計算と順番待ちは進みます。ワーカーは画面のサーバーが起動し、画面を止めても残ります。画面が動いていないときは、Python や MCP が裏で起動します (こちらはジョブがなくなって 5 分たつと終わります)。

      26. Python から使う

      from matsimapi import Client

client = Client()
cu = client.add_sample("Cu")      # ファイルのパスや ASE の Atoms も渡せる: client.add_structure("POSCAR")
stages = [{"ensemble": "nvt", "steps": 1000, "temperature": 300}]

print(client.preview("md", cu, repeat=(3, 3, 3), stages=stages)["estimated_seconds"])
job = client.submit("md", cu, repeat=(3, 3, 3), stages=stages)
job.wait()
print(job.thermo()["summary"])

cna = job.analyze("cna").wait()   # 解析もジョブとして動かす
print(cna.result()["fractions"])

      repeat を省くと、画面と同じ既定値 (セルの厚みが 12 Å 以上になるスーパーセル) を使います。

      MD 以外は client.submit("diffusion", cu, options={...}) のように options で条件を渡します。種類と入力欄は client.kinds() で確かめられます。コマンドでも matsimapi info・matsimapi jobs・matsimapi job 12 などで確認できます。

      リポジトリの外のスクリプトでも、pip install -e で入れていれば data/ を使います。pip で普通に入れた場合に画面と同じデータを使うには、MATSIM_DATA_DIR を設定するか Client(data_dir=...) で指定します。

      27. LLM から使う (MCP サーバー)

      matsimapi mcp が MCP サーバーです。リポジトリの .mcp.json に設定があるので、このフォルダで Claude Code を開くとそのまま使えます。ほかの MCP クライアントでは次のように登録します。

      {"mcpServers": {"matsimapi": {
  "command": "/home/<ユーザー>/.venv/gpumd312/bin/matsimapi",
  "args": ["mcp"],
  "env": {"MATSIM_DATA_DIR": "/home/<ユーザー>/matsim/data"}}}}

      構造の用意・プレビュー・投入・進捗・結果・解析の 31 個のツールがあります。認証がないので標準入出力だけで動かし、ネットワークには公開しません。接続した LLM はログインなしで計算の投入や削除ができ、このマシンのファイルを構造として読めるので、信頼できるクライアントだけに登録してください。
